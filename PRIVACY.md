# Tab Count privacy policy

Effective October 24, 2026

Tab Count is a Chrome extension by developerish that counts and manages open browser tabs. Your tab information stays in your browser. The extension does not transmit user data to the developer or any third party.

## Information used locally

Tab Count reads open-tab titles, URLs, window identifiers, and tab state to show tab counts and lists, switch to tabs, and close tabs at your request. It does not read the contents of web pages, passwords, form fields, or your browsing history.

If you enable duplicate notifications, Tab Count compares the URLs of open tabs. Pending notification actions contain tab identifiers and a URL in Chrome's session storage. This information is removed when the notification is handled or the duplicate tab is closed, and is cleared when the browser session ends or the extension is reloaded, disabled, or updated. It is not a persistent browsing record. Notification text does not include page titles or URLs.

If you enable automatic closing, Tab Count uses Chrome's last-accessed timestamps to identify unused tabs. It checks hourly and keeps active, pinned, playing, loading, incognito, and browser-internal tabs. It does not maintain a separate browsing-history database.

## Settings and retention

Your preferences are saved in Chrome's local extension storage on this device. Tab Count does not use Chrome sync storage. Preferences from older versions may be copied from the extension's local storage when you first open the popup or settings. Uninstalling the extension removes its stored settings and session data.

## Sharing and network activity

Tab Count contains no analytics, advertising, tracking, remote scripts, or network requests. It does not sell, share, or transfer user data. It does not load remote favicons. Chrome's own extension updates and any websites you open are governed by their respective privacy policies.

## Your choices

Duplicate detection and automatic closing are off by default. You can change these settings at any time or remove Tab Count in Chrome's extension settings. The extension does not request access to incognito browsing by default. If you allow that access in Chrome, counts and the tab list can include those tabs; duplicate detection and automatic closing skip incognito tabs.

## Contact and updates

For questions about this policy, [open an issue on GitHub](https://github.com/developerish/tab-count/issues). Do not include private URLs or other sensitive information in a public issue. This policy will be updated if the extension's data practices change.
